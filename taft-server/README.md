# Taft Server

Серверное ядро для карточной мини-игры **Тафт: Карты Альбарадура** —
лёгкая по правилам реализация в духе Гвинта из Ведьмака 3.

## Запуск

```bash
npm install
npm run dev      # Запуск dev-сервера (порт 3000)
npm test         # Запуск тестов
npm run build    # Сборка TypeScript
npm start        # Запуск собранного сервера
```

Сервер по умолчанию запускается на порту `3000` (можно изменить через `PORT`).

## Health-check

```
GET /health → { "status": "ok", "rooms": <number> }
```

## Правила

- Игроки ходят по очереди: сыграть 1 карту или спасовать
- Когда оба спасовали — раунд окончен
- Побеждает тот, у кого больше суммарная сила на поле
- Победа в матче — 2 выигранных раунда из 3

### Подсчёт силы ряда

1. Базовая сила каждой карты
2. Погода — все юниты в ряду получают силу 1
3. Bond — если 2+ карт с тем же именем, сила каждой умножается на количество
4. Morale — +1 всем остальным картам в ряду
5. Horn — удваивает суммарную силу ряда

### Способности карт

- **spy** — карта ложится к противнику, ты тянешь 2 карты
- **bond** — удваивает силу при наличии одноимённых карт в ряду
- **morale** — +1 ко всем остальным картам в своём ряду
- **medic** — позволяет вернуть 1 карту из сброса
- **decoy** — забрать свою карту из ряда обратно в руку
- **frost/fog/rain** — погодные эффекты на соответствующий ряд
- **clear** — убрать все погодные эффекты
- **horn** — удваивает силу выбранного ряда

## Реконнект

При отключении игрока — 30-секундный таймаут. Если не переподключился, ему засчитывается автопас.
