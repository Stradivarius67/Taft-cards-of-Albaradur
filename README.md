# Тафт: Карты Альбарадура

Карточная мини-игра для двух игроков в сеттинге Альбарадура.
Создана для онлайн НРИ-сессий.

## Быстрый старт

### Первый раз
```bash
./setup.sh          # Linux / macOS
setup.bat           # Windows
```

### Запуск для игры
```bash
npm start           # Собирает и запускает на http://localhost:3000
```

### Запуск для разработки
```bash
npm run dev         # Сервер (3000) + клиент (5173) с hot reload
```

### Онлайн-игра
```bash
npm run host        # Сборка + сервер + ngrok одним терминалом
```
Команда сама поднимает сервер, запускает `ngrok http 3000`, забирает у него
публичный URL и кладёт его в буфер обмена. Отправьте ссылку игрокам — один
создаёт комнату, второй вводит код. Ctrl+C останавливает и сервер, и ngrok.

> Требуется установленный [`ngrok`](https://ngrok.com/download) в PATH.

Если хочется по-старому, в два терминала, всё ещё работает:
```bash
npm start           # Терминал 1
ngrok http 3000     # Терминал 2
```

### Standalone exe (для мастера НРИ без npm)
```bash
cd launcher && npm install   # один раз
npm run build:exe             # из корня — собирает launcher/dist/Taft.exe
```
Мастер получает папку с `Taft.exe` + `README.txt`. Запускает двойным кликом,
при первом запуске вводит токен ngrok (`ngrok.yml` сохраняется рядом).
Ссылка копируется в буфер. Закрытие окна останавливает всё.

## Фракции

| Фракция | Стиль | Пассивка |
|---------|-------|----------|
| Львиная гвардия | Синергия, bond/morale | +1 карта при победе |
| Имперские псы | Шпионы, scorch/lock | Побеждают при ничьей |
| Литладские партизаны | Гибкость, muster | Выбор первого хода |
| Серые следопыты | Грубая сила, drain | Карта остаётся между раундами |
| Векситарские ведьмы | Контроль и манипуляция | Тянет карту в начале раунда |

## Механики карт

| Способность | Описание |
|-------------|----------|
| bond | Сила удваивается при наличии одноимённой карты в ряду |
| morale | +1 к силе всех остальных карт в ряду |
| spy | Размещается у противника, вы тянете 2 карты |
| medic | Возвращает карту из сброса на поле |
| decoy | Забирает свою карту с поля в руку |
| horn | Удваивает силу всех карт в выбранном ряду |
| scorch | Уничтожает сильнейшую карту на поле обоих игроков |
| muster | Одноимённые карты из колоды автоматически выходят на поле |
| drain | Отнимает 2 силы у случайной карты противника в том же ряду |
| lock | Блокирует способность одной карты противника |
| frost/fog/rain | Все карты соответствующего ряда обоих игроков получают силу 1 |
| clear | Убирает все активные погодные эффекты |

## Команды

| `npm run dev` | Dev-режим (hot reload) |

| `npm run host` | Production + ngrok одной командой (для онлайн-партии) |
| `npm test` | Тесты |
| `npm run clean` | Очистка |
