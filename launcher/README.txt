ТАФТ: Карты Альбарадура
=======================

Запуск:
  1. Запустите Taft.exe
  2. При первом запуске введите токен ngrok
     (бесплатная регистрация: https://ngrok.com)
     Токен сохранится в ngrok.yml и спрашивать больше не будут.
  3. Скопируйте ссылку (она уже в буфере обмена)
     и отправьте игрокам.
  4. Когда наигрались — закройте окно.

Проблемы:
  - "Порт 3000 занят"         → закройте другую копию Taft.exe
  - "Не удалось создать ссылку" → проверьте интернет
  - Антивирус блокирует exe    → добавьте Taft.exe в исключения
  - Токен отвергнут            → удалите ngrok.yml, запустите заново,
                                 введите свежий токен с ngrok.com

Файлы рядом с exe:
  - Taft.exe      основной исполняемый файл
  - ngrok.yml     токен ngrok (создаётся автоматически при первом запуске)
  - README.txt    этот файл
