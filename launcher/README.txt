ТАФТ: Карты Альбарадура
=======================

Запуск:
  1. Запустите Taft.exe.
  2. Лаунчер автоматически создаст публичную ссылку через Cloudflare.
     Регистрация и токен не нужны. Если Cloudflare недоступен,
     лаунчер автоматически попробует localtunnel.
  3. Ссылка будет скопирована в буфер обмена — отправьте её игрокам.
  4. Чтобы остановить сервер, закройте окно лаунчера.

Проблемы:
  - "Порт 3000 занят"           → закройте другую копию Taft.exe
  - "Не удалось создать ссылку" → проверьте подключение к интернету;
                                   локальная игра продолжит работать
  - Антивирус блокирует exe      → добавьте Taft.exe и cloudflared.exe
                                   в исключения

Файлы рядом с exe:
  - Taft.exe      основной исполняемый файл
  - README.txt    этот файл
